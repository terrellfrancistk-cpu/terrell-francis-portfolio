Privacy & terms

This site collects nothing about you.

terrellfrancis.app is a static résumé site. There is no sign-in, no form, no analytics, no ads, no tracking pixels, and this site sets no cookies.

What your browser stores

  • Splash seen (tf-splash, session storage): stops the opening animation from replaying in the same tab. Cleared when the tab closes.
  • Theme (tf-theme, local storage): only if you pick Light or Dark in the footer. Picking System clears it.

Both stay on your device. Neither is sent anywhere.

Hosting

The site is served by GitHub Pages. Like any web host, GitHub may log technical request data (such as IP address and browser type) to run and secure the service. See the GitHub General Privacy Statement (opens in a new tab).

Fonts and images are served from this site. The one exception is the live demo in the Products section: when you scroll to it, a phone frame loads the selected TK Hub app's own website (for example apexpeakofcare.app), and picking another app loads that app's site. Those sites are run by TK Hub LLC and have their own privacy policies. Nothing else loads from another site.

Links to other sites

Links to LinkedIn, TK Hub LLC apps, and other sites open in a new tab. Those sites have their own privacy policies.

Contacting me

If you email or call using the details on the contact section, I use what you send only to reply. Ask me to delete a message and I will.
